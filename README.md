# Agent 01 — AI Research Assistant 🔍

An AI Research Assistant built using Python and Google Gemini API. The application accepts a research topic and generates a structured research report with sections covering introduction, key concepts, applications, benefits, challenges, and conclusion.

This project is part of my **7 Days, 7 AI Agents** challenge, where I build one AI agent every day to strengthen my practical AI engineering skills.

## 🚀 Features

- Accepts user-provided research topics.
- Uses Google Gemini API for AI-powered research report generation (Live Mode).
- Provides an offline Demo Mode for testing without API access.
- Automatically switches to Demo Mode when the Gemini API request fails.
- Generates structured reports with clearly organized sections.
- Handles missing API keys and invalid user inputs.

## 🛠️ Tech Stack

- Python
- Google Gemini API
- Google GenAI SDK
- python-dotenv

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/vavillakrishnaveni/AI-Agent-Projects.git
```

### 2. Navigate to the project directory

```bash
cd AI-Agent-Projects/agent_01_research
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows CMD:

```bash
venv\Scripts\activate.bat
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure the Gemini API key

Create a `.env` file in the project directory:

```env
GEMINI_API_KEY=your_api_key_here
```

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey).

Never upload your actual `.env` file or API key to GitHub.

## ▶️ Run the Application

```bash
python main.py
```

Enter a research topic and select an execution mode.

### Execution Modes

**1. Live Mode**

Connects to the Google Gemini API to generate an AI-powered research report.

**2. Demo Mode**

Generates a locally defined sample report without requiring an API connection. Demo output is template-based and is not generated by an AI model.

## ⚠️ Current Limitations

- Live Mode depends on Gemini API availability and usage limits.
- Demo Mode uses predefined template content rather than actual AI research.
- Generated AI content should be verified using reliable sources.
- The application currently runs through a command-line interface.
